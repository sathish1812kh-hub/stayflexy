Production Risk Minimization Framework

⚠️ Stale Context / Agent Amnesia

The Risk: Standard AI coding agents operate statelessly. If the system restarts or limits context windows, the agent loses track of pending tasks, previous logic choices, and local drift, leading to regression bugs.

Mitigation: Double-buffered recovery states (Phase 12) coupled with Git HEAD verification (Phase 0). If git branch commit logs do not match current-state.md, execution is frozen until synchronized.

⚠️ Brittle Database Cascades

The Risk: Stayflexi splits its database logically across 16 schemas. Altering columns in tables (like User, Organization, or Booking) without cascade validation can result in orphaned rows or database locking in production.

Mitigation: Continuous AST parsing via Tree-sitter and Neo4j schema check. Automatically analyzes foreign key cascade constraints before committing database migrations.

⚠️ Port & Dependency Collisions

The Risk: Running background microservices and telemetry scrapers can occupy ports, collide with local processes, or bloat production Docker images with dev-only binaries.

Mitigation: Decoupled orchestration. Tooling runs on background containers and local python environments. Production Dockerfiles use multi-stage builds containing zero devDependencies.

Software In-Depth & Enterprise Rationale

Tree-sitter

Syntax Tree Parser

Why We Use It

Standard text parsing using Regular Expressions (regex/grep) is brittle and results in false positives when locating references. Tree-sitter parses the source code into a syntax tree (AST) in milliseconds, allowing accurate extraction of models and imports.

Prisma Relationship Mapping Maps schema foreign keys and verify cascades automatically.
Incremental Compilation Only parses modified files, ensuring zero performance lag.

Graphiti

Semantic Memory Layer

Why We Use It

Microservice structures and database configurations define *what* the application is, but git commits and decisions explain *why* it was built. Graphiti processes unstructured logs and decisions to build an AI memory graph.

Stateless Context Recovery Enables coding agents to recover full task contexts across sessions instantly.
Git-Commit Association Links specific commit hashes directly to the code components they modified.

Neo4j

Knowledge Graph Database

Why We Use It

Tracing imports and routes across 11 microservices requires complex recursive queries. Relational databases like Postgres require nested JOINs that are too slow. Neo4j allows executing multi-hop dependency queries in milliseconds.

Impact Analysis Queries database-to-route dependencies instantly using Cypher.
Live State Tracking Stores structural code components as nodes (Services, Endpoints, Tables).

Graphify

Static Analysis Scanner

Why We Use It

Provides a lightweight static directory analysis. By keeping its scanning logic inside python helper scripts, we avoid loading heavy compiler libraries directly into Node process runtimes.

JSON AST Caches Stores static file definitions under graphify-out/.
Obsidian Integration Generates obsidian documentation files of methods and variables.
